# ESP32Robot Examples

Three simple examples to get started. Do them in order!

---

## 1. [Telemetry](telemetry/) — Send Data to the Web Page

- **Hardware:** Just an ESP32
- **Learn:** How to connect to Wi-Fi and display live data on the web page

## 2. [Motors](motors/) — Control Motors Directly

- **Hardware:** ESP32 + motor driver + 4 motors
- **Learn:** How to create motors, build a drivetrain, and drive in a pattern

## 3. [WiFi Drive](wifi_drive/) — Control the Robot over Wi-Fi

- **Hardware:** ESP32 + motor driver + 4 motors
- **Learn:** How to use the web controller to drive your robot with W/A/S/D

---

## Getting Started

1. **Change the Wi-Fi credentials** in the code to match your network
2. **Change the pin numbers** to match your motor wiring
3. **Upload** the sketch to your ESP32
4. **Open the Serial Monitor** (115200 baud) to find the IP address
5. **Open that IP** in any web browser to see the controller
